## 目标

在不破坏 CREHN 现有门户 CMS、权限和不可变发布边界的前提下，为“创意河南”公共门户建立受控的主题样式配置和多个布局保存/切换基础，使后续首页和专题页可以复用同一套布局与主题契约。

## 范围

- `portal/`：主题令牌、布局版本选择、响应式布局数据契约和安全默认值。
- `frontend/src/views/crehn/cms/`：门户主题与布局配置入口的基础交互，沿用现有权限指令。
- `backend/ruoyi-modules/ruoyi-crehn/`：门户配置读取/保存/发布契约的最小适配（如确有必要）。
- `deploy/db/migrations/`：仅在代码契约需要时增加未执行的结构迁移；本任务不执行 SQL。
- 主题配置只允许白名单令牌；布局只保存组件标识、栅格、顺序和受控配置。
