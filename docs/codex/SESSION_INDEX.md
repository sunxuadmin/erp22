## 以后记录规则

- 新工作先在 `00-项目总控调度` 选择/创建唯一任务编号和任务卡。
- 临时子代理只完成限定子任务，不创建自己的长期总控清单。
- 结论先写入任务卡；影响多模块且难回退的结论再写 `DECISIONS.md`。
- 完成后把验证证据、未验证项和下一步写入 `HANDOFF.md`，然后才评估会话归档。
