# CREHN 角色、权限与数据范围

## 1. 权限模型

每次请求必须同时通过四层校验：

1. 身份：当前账号是谁、账号是否启用；
2. 功能权限：是否具有操作权限标识；
3. 数据范围：是否能访问目标活动、学校、任务和记录；
4. 业务状态：目标记录是否处于允许操作的状态。

前端路由、菜单和按钮只负责用户体验，不能代替后端校验。

## 2. 业务角色

| 角色 | 默认职责 | 默认数据范围 |
|---|---|---|
| 超级管理员 | 系统、全局角色、活动和运维 | 全部，但危险操作仍需二次确认和审计 |
| 活动管理员 | 活动配置、学校范围、审核评审和结果 | 被授权活动 |
| 次活动管理员 | 与活动管理员相同的权限模型，可减少权限 | 被授权活动及明确权限集合 |
| 学校联络员 | 名单、学校审核、推荐和最终批次提交 | 本校、被授权活动 |
| 参赛者 | 本人资料、本人作品和本人消息 | 本人账号及本人参与作品 |
| 省级审核员 | 形式审查和审核意见 | 有效审核分配 |
| 评委/专家 | 专家任务、材料查看和单评委评分 | 有效评审分配 |
| 评分汇总员 | 查看评分、签名和汇总导出 | 被授权活动，只读 |
| 结果管理员/发布人 | 结果规则、生成、锁定和发布 | 被授权活动和权限 |
| CMS 编辑 | 栏目、文章和媒体草稿 | 被授权门户范围 |
| CMS 发布 | 审核、发布、下线和回滚 | 被授权门户范围 |
| 监督审计员 | 查看操作、导入、导出和发布日志 | 授权范围，只读 |

一个账号可拥有多个角色，但权限取并集后仍受活动、学校、任务和状态限制。

## 3. 学校数据范围

- 所有学校业务实体必须具有权威 `school_id`。
- 学校账号只能访问本校账号、参赛者、作品、批次和消息。
- 学校范围不能依靠前端筛选参数；后端必须从登录身份解析学校。
- 导出使用与列表相同的数据范围和筛选条件。
- 学校停用不删除历史作品；只阻止新增和后续业务操作。

## 4. 参赛者范围

- 参赛者账号必须绑定本人 `participant_profile`。
- 学校预导入的资料在参赛者首次激活后必须由本人确认。
- 参赛者只可维护本人参与且处于可编辑状态的作品。
- 共同作者通过邀请和确认建立关系；不能仅凭姓名让他人获得账号权限。
- 身份证号、手机号、邮箱、学号/工号按字段敏感级别脱敏。

## 5. 审核员和专家范围

- 审核员仅访问有效审核任务覆盖的活动、类别、学校和项目。
- 专家仅访问有效评审任务；任务停用后立即失去访问权。
- 回避学校、冲突项目和动态筛选条件在分配和读取时都要校验。
- 匿名模式由服务端生成匿名视图，禁止返回学校、作者、联系人、文件原名或可反推身份的元数据。
- 专家之间默认不可互看评分；显示时机由活动配置和服务端策略决定。

## 6. 管理权限

- 超级管理员拥有兜底能力，但重置密码、替代激活、强制撤回、评分调整和结果发布必须填写原因。
- 次活动管理员不得通过创建新角色绕过自身权限。
- 活动管理员只能向其管理范围内的角色和账号授予活动权限。
- 评分汇总员不能直接调整评分或生成结果，除非另行获得对应权限。

### 6.1 界面配置权限

- 超级管理员可以维护系统默认主题、系统骨架、角色模板和全部活动的界面配置；高风险发布和恢复默认必须审计。
- 活动管理员可以维护被授权活动的门户主题、角色首页、角色工作台、页面/类别布局、表格列、按钮呈现和状态文案。
- 次活动管理员只有获得明确到配置范围的权限后，才能修改指定活动、角色或页面；不得通过导入配置扩大自身权限。
- CMS 编辑与 CMS 发布只分别维护门户内容草稿和内容发布，不因 CMS 权限获得业务工作台配置权。
- 参赛者、学校联络员、审核员、评分员、汇总员、结果管理员和监督审计员默认只能使用已发布界面，不能修改权威配置。
- 监督审计员可以查看配置版本、差异、发布和回滚日志，但保持只读。

界面配置必须绑定稳定的 `activity_code`、`role_key`、`page_key`、`component_key`、`category_code`、`field_key` 和 `action_key`。禁止把角色数字 ID、菜单数字 ID、用户 ID 或活动数字 ID 写入可迁移配置。

## 7. 文件与导出

- 文件列表、元数据、预览地址和下载地址均按数据范围生成。
- 无权文件不能先返回元数据再由前端隐藏。
- 导出必须记录操作人、角色、活动、学校、筛选、字段范围、文件校验值和下载时间。
- 高敏导出可要求二次确认、有效期和水印。

## 8. 账号生命周期

账号状态包括待激活、启用、停用、锁定、回收站和归档。密码、一次性激活码和重置凭证不得可逆保存或写入日志。账号删除不得级联删除历史作品、审核、评分或发布记录。
