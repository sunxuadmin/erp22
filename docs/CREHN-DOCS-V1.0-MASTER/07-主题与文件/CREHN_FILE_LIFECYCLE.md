# CREHN 文件生命周期规范 V1.1

## 1. 文件分类

| 分类 | 示例 | 关键约束 |
| --- | --- | --- |
| 模板文件 | 报名表、成员表、承诺书模板 | 版本化、适用范围、不可静默替换 |
| 业务附件 | 作品、证明、身份证明 | 活动/项目/字段绑定、数据范围授权 |
| 生成文件 | 导出表、签名评分表、结果公示 | 记录生成规则、版本和哈希 |
| 预览衍生物 | 缩略图、PDF、转码音视频 | 随原文件授权，不是独立公开资源 |
| CMS 媒体 | Banner、图片、视频 | 站点发布版本和公开范围 |
| 临时文件 | 分片、导入包、中间文件 | TTL、失败清理、不可作为正式引用 |

## 2. 状态机

```text
PENDING → UPLOADED → SCANNING → ACTIVE
                         └────→ REJECTED
ACTIVE → DELETED → PURGED
```

- `PENDING`：已创建上传会话；
- `UPLOADED`：对象传输完成且哈希可校验；
- `SCANNING`：安全扫描、格式识别和必要转码中；
- `ACTIVE`：可以按授权绑定、预览或下载；
- `REJECTED`：安全或格式校验失败，禁止业务引用；
- `DELETED`：逻辑回收，仍保留审计和恢复窗口；
- `PURGED`：超过保留期且无合规保留要求后物理清理。

状态转换只能由 FileService 和受控任务执行。

## 3. 元数据与绑定

文件至少记录：文件标识、原始名、扩展名、MIME、大小、哈希、存储提供方、对象键、分类、状态、创建人/单位、扫描结果、预览状态、创建/删除时间和保留策略。

业务绑定单独记录：业务类型、业务标识、字段键、活动、配置版本、显示顺序、可见级别、绑定/解绑人。一个物理对象可去重，但授权始终按业务绑定计算。

## 4. 上传

- 小文件可由服务端中转，大文件采用受控直传或分片上传；
- 创建上传会话前校验身份、功能权限、数据范围、业务状态、字段规则和配额；
- 上传完成后校验大小、哈希、MIME 与真实文件特征；
- 扫描和预览尚未完成时，业务页面显示处理中，不得伪装成功附件；
- 上传会话、分片和临时对象必须有过期清理。

## 5. 预览和下载授权

- 每次请求由服务端依据当前身份、功能、数据范围、业务状态和文件绑定授权；
- 对象存储保持私有，临时签名地址短时有效且不得写入数据库或日志；
- 服务端不能在授权判断前返回可猜测的对象键、文件元数据或下载地址；
- 专家匿名材料由专用查询模型生成，去除姓名、学校等规则指定信息；
- 导出敏感文件需要单独权限、水印或下载审计。

## 6. 删除与保留

- 草稿文件可按规则解绑并进入回收；已提交、已评分、已签名或已发布文件受业务状态限制；
- 删除前统计业务绑定、历史版本和发布引用；
- 业务删除不立即物理删除对象；
- 签名评分表、审计证据和已发布结果按档案保留策略保存；
- 定时清理仅处理无有效绑定、超过保留期且无冻结标记的对象，并生成报告。

## 7. DYZ 兼容资源

- 导入包只携带资源清单、逻辑引用、哈希和受控资源文件，不信任 DYZ OSS ID 或 URL；
- 导入时先扫描、校验哈希、创建 CREHN 文件，再建立业务绑定；
- 缺失、重复、超限和不支持格式必须进入迁移报告；
- 重复导入按包标识、资源哈希和业务幂等键处理，不产生孤儿文件；
- 禁止 CREHN 读取 DYZ 生产存储凭据或将两个环境配置为同一业务 bucket。

## 8. 验收重点

- 未登录、跨单位、未分配专家、失效链接和状态变更后的访问均被服务端拒绝；
- 伪造 MIME、恶意文件、超大文件、重复分片、断点重试和扫描失败有明确结果；
- 预览衍生物、原文件、导出文件的权限一致；
- 删除、恢复、超期清理和兼容导入均可审计并可对账。
