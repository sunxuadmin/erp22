# CREHN 上线验收清单 V1.1

## 1. 使用规则

- 本清单是发布门禁摘要，详细用例和证据登记见 [验收矩阵](CREHN_ACCEPTANCE_MATRIX.md)。
- 每项必须记录版本、环境、执行人、时间、结果和证据位置。
- `NOT_RUN`、`NEEDS_BROWSER`、`NEEDS_SERVER` 不得标记为通过。
- 阻断级缺陷、数据越权、迁移不一致、不可恢复备份或无回滚方案时禁止上线。

## 2. 产品与流程

- [ ] 每位参赛者可获得正式账号并本人激活，学校批量导入/激活码和省级兜底可审计。
- [ ] 全部学校清单导入、启停、账号分配和影响统计正确。
- [ ] 报名开放时间默认支持 2026-09-01 00:00，并可由管理员后期调整和发布版本。
- [ ] 报名、学校审核推荐、统一提交、项目审核、专家评分、汇总、结果发布全流程闭环。
- [ ] 评分汇总、结果草案和已发布结果严格区分。
- [ ] 独立门户文章、媒体、首页组件、预览、定时发布和回滚可用。

## 3. 权限与数据范围

- [ ] 超级管理员、活动/次活动管理员、审核员、评分员、汇总员、学校和参赛者权限符合矩阵。
- [ ] 跨学校、跨活动、跨专家分配、跨审核范围访问均被服务端拒绝。
- [ ] 菜单隐藏与按钮隐藏不是唯一控制，接口和文件下载独立鉴权。
- [ ] 批量、统计、导入、导出和预览接口执行相同的数据范围。

## 4. 状态与并发

- [ ] 活动、项目、学校批次、审核、评分、签名表、结果和 CMS 状态只能合法迁移。
- [ ] 重复点击、重复请求、并发编辑、版本冲突和任务重试不会生成重复数据。
- [ ] 已提交/已锁定/已发布数据不能被无痕修改，解锁和撤回有原因及审计。
- [ ] 时间边界、时区和定时任务经过前后一分钟及失败补偿测试。

## 5. 动态配置

- [ ] 字段、成员、附件、评分、表格、主题和页面配置具有唯一来源和发布版本。
- [ ] 条件必填、人数范围、附件限制、跨字段规则和服务端校验一致。
- [ ] 历史项目按历史快照显示，字段停用不会丢失历史语义。
- [ ] Excel 模板版本、逐行错误、预览确认、幂等导入和错误报告正确。

## 6. 文件

- [ ] 上传、分片、扫描、预览、授权下载、回收、恢复和清理状态完整。
- [ ] 对象存储私有，临时地址失效后不可复用，原文件与预览权限一致。
- [ ] 恶意、伪格式、超限、缺失资源和孤儿对象有处理及对账。
- [ ] 签名评分表、结果文件和审计材料满足保留策略。

## 7. DYZ 兼容与迁移

- [ ] DYZ 包的格式版本、校验值、稳定编码、资源和引用完整性先校验后导入。
- [ ] dry-run 显示新增、映射、冲突、跳过、失败和资源影响。
- [ ] 新建独立活动是默认导入模式，不共享数据库主键、账号、OSS ID 或存储凭据。
- [ ] 重复导入幂等，不产生重复活动、项目、成员、评分或文件。
- [ ] 未知字段/状态/版本阻断或进入显式待处理，不能静默丢弃。
- [ ] 回滚和导入后对账通过。

## 8. 安全、性能与运维

- [ ] 密码、激活码、证件号、手机号、匿名材料和未发布结果受到保护。
- [ ] 限流、重放防护、依赖扫描、安全响应头和生产配置通过检查。
- [ ] 峰值报名、批量导入、文件上传、评分并发、汇总和门户访问满足指标。
- [ ] 日志、指标、追踪、业务告警和任务告警可用且不泄露敏感信息。
- [ ] 数据库、对象、配置和密钥元数据备份完成，并有隔离环境恢复演练证据。

## 9. 发布与回滚

- [ ] 代码、前端产物、数据库迁移、配置和对象存储策略有版本及校验值。
- [ ] 发布清单、目标环境、维护窗口、责任人和回滚触发条件明确。
- [ ] 发布前备份、发布后健康检查、关键 API、登录、文件和持久化回读通过。
- [ ] 回滚脚本/步骤经过演练，确认不会破坏已产生的新业务数据。
- [ ] DYZ 环境和数据未受 CREHN 发布影响。
