# CREHN 验收矩阵 V1.1

## 1. 证据格式

每条用例记录：

| 字段 | 说明 |
| --- | --- |
| Case ID | 稳定编号，例如 AUTH-001 |
| 版本 | Git/构建/数据库/配置版本 |
| 环境 | 本地、测试、预生产或生产 |
| 前置数据 | 活动、学校、账号角色、项目状态 |
| 操作 | 可复现步骤或自动化命令 |
| 预期 | 页面、API、数据库、文件和审计结果 |
| 结果 | PASS、FAIL、NOT_RUN、NEEDS_BROWSER、NEEDS_SERVER |
| 证据 | 测试报告、截图、日志、查询或任务报告位置 |

未经实际执行不得填写 `PASS`。

## 9. 发布判定

- 安全、数据越权、评分锁定、结果版本、文件授权、兼容迁移、备份恢复属于阻断项；
- 阻断项全部 `PASS`，其他失败项有经批准的处置和延期范围，才可申请生产发布；
- 生产发布仍需单独授权，验收通过不自动等于允许部署。
