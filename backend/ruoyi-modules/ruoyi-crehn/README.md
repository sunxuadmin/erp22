# ruoyi-crehn

省级大学生艺术展演评审业务模块。

## 模块范围

- `registration`: 注册码生成、校验、使用记录、作废。
- `activity`: 活动、阶段、项目类别、动态字段、附件要求、评分规则。
- `school`: 学校名单、联系人、学校账号、学校名额。
- `project`: 项目申报、成员、附件、草稿、提交、退回修改。
- `audit`: 材料审核、审核通过、退回修改、审核记录。
- `expert`: 专家库、专家组、专家账号、回避规则。
- `review`: 评审任务分配、评分草稿、提交锁定、退回重评。
- `result`: 分数汇总、排名、奖项、复核、锁定、发布。
- `report`: 首页统计、学校统计、类别统计、专家统计、导出任务。

## 开发约定

- API 路径使用 `/crehn/<module>/...`。
- 权限标识使用 `crehn:<module>:<action>`。
- 服务端必须做数据权限校验，学校只看本校，专家只看分配任务。
- 状态流转、审核、评分、结果锁定、导出等关键动作必须写操作日志。
- 不在系统模块里写评审业务逻辑，系统模块只保留用户、角色、菜单、字典、参数、日志等基础能力。
