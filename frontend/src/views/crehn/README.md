# Art Review Views

本目录存放省级大学生艺术展演评审系统后台业务页面。

## 目录规划

- `registration`: 注册码管理页面。
- `activity`: 活动管理、类别配置、材料配置、评分规则页面。
- `school`: 学校名单、联系人、名额、统计页面。
- `project`: 项目列表、申报详情、附件页面。
- `audit`: 待审核、审核记录页面。
- `expert`: 专家库、专家组、回避规则页面。
- `review`: 项目分配、评审进度、专家任务页面。
- `result`: 分数汇总、结果复核、发布页面。
- `report`: 首页统计、学校/类别/专家统计、导出任务页面。

页面权限标识应使用 `crehn:<module>:<action>`。
